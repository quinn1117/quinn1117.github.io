linux中yum和apt的区别

apt和yum核心功能类似，但是两者依赖的底层包格式不同

apt（Advanced Package Tool)

apt处理的软件包格式为.deb，包含了预编译的二进制文件以及相关的元数据。

yum(Yellowdog Updater, Modified)

yum处理的软件包格式为.rpm，同样包含了预编译的二进制文件以及相关的元数据，但处理依赖的机制有所不同。

VSCode远程ssh连接VitualBox虚拟机设置免密登录

前提基础：给虚拟机ssh的22端口设置端口转发为主机端口2222，vscode已经通过2222端口连接上虚拟机。

步骤：

  1. 在本地主机终端中执行命令生成密钥：ssh-keygen -t rsa -b 4096
  2. 进入生成的.ssh目录
  3. 在远程主机根目录下创建.ssh
  4. 在本地主机终端执行命令上传：scp -P 2222 id_rsa.pub han@localhost:~/.ssh/.
  5. 在远程主机.ssh目录下执行：cat id_rsa.pub >> authorized_keys生成authorized_keys文件就成功了

这样下次使用vscode不用再输入密码，打开即用

静态库

程序在编译的过程中把已经编译好的二进制文件链接到目标程序中，成为静态链接

动态库

我们发现动态库和静态库链接命令一样，编译器是如何解决到底链接哪个呢？

当动态库（.so）和静态库（.a）同名且存在于同一目录时，编译器会优先链接动态库。

如果需要强制链接静态库，需要显式指定路径或者使用-static选项。

同时我们发现demo.cpp里链接public.hpp头文件用的头文件的相对路径，但是路径变了代码就得改，所以把lib删去只保留文件名，这样编译命令只需要加上-I和路径即可。

makefile

当程序文件过多时，但是库文件都是链接的同一份，这时候makefile可以简化

main函数的参数

argc表示参数个数，argv存放argc个参数的数组，envp是环境变量数组。

设置环境变量，仅对本进程有效：

int setenv (const char *__name, const char *__value, int __replace);

获取环境变量的值：

char *getenv (const char *__name) __THROW __nonnull ((1)) __wur;
